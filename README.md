# 🌡️🚨 Smart Dual Sensor Alarm System

## 📌 Project Description

The **Smart Dual Sensor Alarm System** is an Arduino-based safety and monitoring project designed and simulated using Tinkercad Circuits. It combines a temperature sensor and a PIR (Passive Infrared) motion sensor to monitor environmental temperature and detect human movement.

The system processes readings from both sensors using an Arduino microcontroller and activates an alarm when the programmed conditions are met. This project demonstrates how combining multiple sensors can improve basic safety monitoring and automation.

## 🎯 Objectives

- Monitor temperature changes using a temperature sensor.
- Detect human movement using a PIR sensor.
- Generate an alarm when predefined conditions are triggered.
- Understand Arduino programming and sensor interfacing.
- Explore dual-sensor monitoring through circuit simulation.

## ⚙️ Technologies Used

- **Simulation Platform:** Tinkercad Circuits
- **Microcontroller:** Arduino Uno
- **Programming Language:** Arduino C/C++
- **Sensors:** Temperature sensor and PIR motion sensor
- **Output Components:** Buzzer and/or LED, depending on the circuit

## ✨ Key Features

- Dual-sensor monitoring.
- Temperature-based alert detection.
- PIR-based motion detection.
- Automatic alarm activation.
- Virtual circuit simulation using Tinkercad.
- Simple and cost-effective safety system design.

## 🔄 How It Works

1. The temperature sensor continuously measures the surrounding temperature.
2. The PIR sensor detects movement in its field of view.
3. The Arduino reads and processes the sensor outputs.
4. The program checks whether the configured temperature threshold or motion condition has been triggered.
5. When an alarm condition is met, the connected buzzer or LED activates.
